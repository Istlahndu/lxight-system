使用资源观测工作台
从左侧选择节点、进程或线程；多个 rank 使用统一时间轴。流水线总览将软件算子按类别着色，按类别分轨可展开帧、矩阵、向量、交换、请求和等待。演示夹具仅验证界面和分析规则，不代表 LX2 已具备相应硬件采集能力。
驻留
目标线程、其他执行、已证实 idle 和 unknown 分开。线程被换出后不延伸到旧核。
计数窗与样本
计数保留完整窗口，不按选区长度均摊；采样不填成连续状态。/proc CPU 点只表示最后运行位置，不是连续驻留。
选区与视图
拖动框选后点击“放大到选区”，将选中时间段铺满横轴；时间线获得焦点时可按 Z。放大后拖动底部水平滚动条左右浏览。选区决定统计，缩放和平移只改变视图。悬停对象可查看名称、起止时间和持续时间，点击查看原始证据。F 全览，Esc 清除对象选择。
硬件重叠
只有经验证且可校时的计算与传输活动边界才可计算。缺源时 unavailable。
离线
可导入 v2 JSON、导出选区 JSON/CSV 和自包含 HTML。旧 v1 请先通过 CLI 只读迁移。
