分析工作台使用帮助
导入版本化会话包后，按线程查看帧、算子、显式交换与等待。应用标注代表软件意图；本 Demo 不重建逐核驻留或硬件 busy。
选区
在时间线上拖动，或输入起止毫秒；点击帧 / 事件后可把它设为选区。
帧筛选
选择一个应用 frame 后，时间线与统计只保留该 frame；“全部帧”用于观察流水线并发。
轨道显示
“帧内类别轨道”按 frame 和类别拆行；“计算轨道”仅隐藏非计算范围。统计仍按选区、线程和帧筛选计算。
缩放 / 平移
使用 ＋ / − 或滚轮缩放，Shift + 拖动平移；F 全览，Esc 清除高亮。
检索与关联
搜索算子 / 帧 / 请求，↑ / ↓ 跳转结果。点击范围查看父子事件、等待对象及提交到完成的 flow。
统计与缺失
先在每线程扣除等待 / 交换，再取计算并集。未闭合事件保持 end_ts=null，不纳入精确耗时。缺失时比例为 N/A。
离线导出
JSON / CSV 导出当前选区与父级上下文。Trace Event 用于兼容查看器；原生会话保留完整能力、质量和来源信息。
